# hanmingzhou.github.io

[韩火火吃小兔のHexo](https://hanmingzhou.github.io) — Hexo + [ParticleX](https://github.com/theme-particlex/hexo-theme-particlex) 主题。

-   `hexo` 分支：博客源码（文章、配置、主题）
-   `master` 分支：GitHub Actions 自动构建产物，GitHub Pages 由此发布，请勿手动修改

写文章、放图片、部署的完整说明见 [GUIDE.md](GUIDE.md)。

```bash
npm install
npm run server   # http://localhost:4000
```
